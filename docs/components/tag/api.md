# Tag API

These are named public Props; inherited capabilities belong to their own public API.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `parts` | `ComponentPartsOf<{ Button: typeof Button }>` | — | Configure the close Button generated by Tag. Does not affect Buttons supplied inside explicit children. |
| `variant` | `"default" \| "active"` | "default" | Appearance variant. default uses a Black/4% background; active uses a Brand 10% background and Brand text. |
| `toggle` | `boolean` | false | Shorthand for Toggle mode. Internally sets Click={{ Idle: "Active", Active: "Idle" }} and whileClick=false. Frame exposes data-state="Active" to trigger the Brand active appearance and outputs aria-pressed. Explicit Click or whileClick values still take priority. |
| `closable` | `boolean` | false | Show the built-in X remove control, which becomes visible on Tag hover. |
| `shape` | `"default" \| "left-arrow" \| "right-arrow"` | "default" | Shell shape for path or breadcrumb segments. |
| `onClose` | `(event: MouseEvent) => void` | — | Callback when the X is clicked. Tag does not destroy itself; the consumer decides how to remove it. |
| `children` | `Snippet` | — | Displayed label content rendered through the Frame children protocol. The component manages its close Button separately. |
