# ImageGroup

Arrange multiple images with consistent sizes and group preview for galleries and attachments.



Package: `@snowui-design-system/components`. Import: `import { ImageGroup } from '@snowui-design-system/components';`. Source fingerprint: `8af02c03f39449d5bd6ddd5b211f09463b78062df2adcd90d0996088f8da4a78`.

## Usage choices

Use ImageGroup to organize images under shared configuration. Pair it with ImageViewer for full-screen viewing, zoom, or navigation between images. Express layout and image loading state through the public API.

- Choose group layout with layout and shared image size with size.
- Image children join the media group automatically. An explicit child size or previewMode overrides group defaults.
