# Text

<a id="组件介绍"></a>

## Overview

Display text with consistent typography and truncation for body copy, labels, and space-limited information.

<a id="使用选择"></a>

## When to use it

Use Text for semantic text, truncation, expansion, and supplementary tooltips. Hover motion is off by default. Plain static copy may use semantic HTML; choose a motion component for animated numbers or text.

- `tag` chooses the text element, `lines` controls truncation, and `more` or `tooltip` supplies expansion or additional information.
- No hover interaction runs by default. `stateText` can replace copy by state; `parts` configures built-in Button and Tooltip instances.
- With lines=1, shortened visible text retains its complete accessible name, including when used inside a button, link or native label.

<a id="快速开始"></a>

## Quick start

This example shows the recommended basic composition. See the sections below for more cases and composition limits.

```svelte
<script lang="ts">
	import { Text, Button, Frame } from '@snowui-design-system/components';
</script>

<div style="width: min(100%, 24rem); min-width: 0;">
	<Text lines={1} tooltip style="font-size: var(--text-14); line-height: var(--leading-14); width: 100%;">Design system documentation — component behavior, accessibility, and release notes</Text>
</div>
```

<a id="api"></a>

## API

| Keyword | Type | Default | Description |
| --- | --- | --- | --- |
| tag | `string` | — | Root element tag; defaults to `span`. |
| stateText | `StateValueMap<string \| number>` | — | Render text for the nearest parent Frame’s `currentState`. Fall back to `stateText.Idle`, then `children`. |
| interactive | `boolean` | `false` | Enable Text hover motion only when explicitly set to `true`; off by default. |
| lines | `0 \| 1 \| 2 \| 3` | — | Text truncation mode: `0` = expandable, `1/2/3` = fixed number of lines. |
| more | `boolean` | `false` | Generate a built-in expansion Button when `lines=0`; the default style is the ArrowLineDown button in Example 6. |
| tooltip | `TooltipProp` | — | Tooltip configuration: derive text automatically, pass fixed text or a Snippet, or pass an object to override placement, offset, and other Tooltip settings. |
| onTruncate | `(isTruncated: boolean) => void` | — | Truncation state change callback. |
| children | `Snippet<[any]>` | — | Default text or custom content, receiving a render context with the breakpoint. Matching `stateText` replaces it with the state-specific text. |
| parts | `ComponentPartsOf<{ Button: typeof Button; Tooltip: typeof Tooltip; }>` | — | Configure built-in Button and Tooltip instances only; same-named components passed as children do not inherit these parts. |

See the base component documentation for inherited capabilities not redeclared here. This table lists only named public Props declared by this component.

## Usage boundaries and details

<a id="内置组件双模式"></a>

<a id="内置组件双模式-1"></a>

### Built-in component dual mode

- `parts.Button`: Configures the built-in expand button generated by `lines={0}` + `more`; pass `<Button as="more">` in `children` to replace it explicitly.
- `parts.Tooltip`: Configures the built-in truncation Tooltip, or pass `<Tooltip as="tooltip">` explicitly without private Text selector side effects.
- When `lines` is omitted, the truncation controller stays dormant without reading text or registering `MutationObserver` / `ResizeObserver`.

<a id="布局模型"></a>

<a id="布局模型与截断行为"></a>

### Layout model and truncation behavior

Primary layout model: **text flow layout**.

- `tag` selects `block` (`p`, `h1-h6`, `div`, with `overflow-wrap: break-word`), `inline-block` (`span`, etc.), `list-item` (`li`), or `code` display mode without adding internal padding, gap, or margin that alters surrounding text flow.
- **Single-line truncation (`lines={1}`)**: Uses `fitTextToElement()` to place the ellipsis flush with visible text while preserving the full accessible text in a visually hidden span.
- **Multi-line truncation (`lines={2 | 3}`)**: Applies `line-clamp` and `text-box-trim: trim-end` on a dedicated inner layer while keeping Tooltip anchored to the root.
- **Height-constrained expand and scroll (`lines={0}`)**: Enabling `more` (or passing `<Button as="more">`) adds a bottom fade mask and bottom-right expand button that transitions smoothly to full height; omitting `more` switches to top/bottom scroll masks with an overlay scrollbar.

<a id="statetext-解析规则"></a>

### `stateText` parsing rules

1. Reads `currentState` from the nearest parent Frame context, rendering `stateText[currentState]` when matched and falling back to `stateText.Idle` and `children`.
2. Use `stateText` only for plain-text replacement within a fixed structure; use Frame `stateContent` for subtree swaps, and prefer `Pending` over `Load` when displaying live in-progress button labels.

<a id="使用示例"></a>

### Examples

```svelte

<Text>Plain text without truncation.</Text>


<Text lines={1}>Very long text that will be truncated...</Text>


<Text lines={0} more style="max-height: 4.5rem;">
    Long content that expands when requested.
</Text>


<Text lines={0} style="max-height: 4.5rem;">
    Long content that expands when requested...
    <Button as="more" variant="borderless">Read more</Button>
</Text>


<Text lines={0} style="height: 5rem;">
    Long content that scrolls within a fixed height.
</Text>


<Button Click="Active" Active={["Idle", "auto"]} whileActive={{ duration: 2000 }}>
    <Icon stateIcon={{ Idle: Paperclip, Active: Check }} />
    <Text stateText={{ Idle: "Copy", Active: "Copied" }} />
</Button>
```
