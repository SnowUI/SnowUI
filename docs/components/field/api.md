# Field API

These are named public Props; inherited capabilities belong to their own public API.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `invalid` | `boolean` | false | Invalid state for the whole field, forcing an error border. |
| `readonly` | `boolean` | false | Read-only state for the whole field. |
| `label` | `string \| Snippet` | — | Generate an internal <Text as="label">. No label is generated by default. |
| `error` | `string \| Snippet` | — | Generate an internal <Text as="error"> when invalid=true. No error is generated by default. |
| `parts` | `ComponentPartsOf<{ Text: typeof Text }>` | — | Configure the generated label and error Text components. |
| `children` | `Snippet` | — | Field content composed freely from inputs and related elements. |
