# Segmented

<a id="组件介绍"></a>

## Overview

Show a small set of mutually exclusive choices side by side for quick changes to filters or parameters, with keyboard and form support.

<a id="使用选择"></a>

## When to use it

Use radiogroup semantics for choosing one parameter or filter. Use Tab when switching content panels or views.

- Use `bind:value` and stable option values. If the value is absent or unmatched, the first available item appears selected, but the binding is not updated automatically; initialize form state explicitly.
- For explicit items, use `Button as="item"`. A nonempty `name` adds a hidden form field; the application restores the initial bound value on form reset.

<a id="快速开始"></a>

## Quick start

This example shows the recommended basic composition. See the sections below for more cases and composition limits.

```svelte
<script lang="ts">
	import { Segmented } from '@snowui-design-system/components';
</script>

<Segmented size="lg" value="all" aria-label="Filter components by category" items={[{ value: 'all', label: 'All' }, { value: 'basic', label: 'Basic' }, { value: 'composite', label: 'Composite' }]} />
```

<a id="api"></a>

## API

| Keyword | Type | Default | Description |
| --- | --- | --- | --- |
| value | `string` | — | Current unique option value; supports `bind:value`. Clicking or activating with arrow keys updates it. If missing or unmatched, the first available item appears selected without writing back to the binding; initialize form state explicitly. |
| name | `string` | — | A nonempty name adds a hidden input with that name so native FormData receives the current value. An undefined value submits as an empty string. Place it inside a form and restore the initial bound value on reset. |
| children | `Snippet` | — | Explicit item content as a parameterless snippet. Use `Button as="item"` with a unique value. It takes precedence over `items`; configure each Button directly. |
| class | `string` | `""` | Merge an external class into the real Tab root while preserving Segmented identity; it does not hide the form input. |
| parts | `ComponentPartsOf<{ Button: typeof Button }>` | — | Configure Buttons generated by `items` through `parts.Button`, such as `scaleOnHover`. Explicit child Buttons are configured individually; there is no `parts.Tab`. |

See the base component documentation for inherited capabilities not redeclared here. This table lists only named public Props declared by this component.

<a id="使用边界与详细说明"></a>

## Usage boundaries and details

<a id="默认内置模式-显式组合模式"></a>

<a id="默认内置模式-显式组合模式-1"></a>

### Default built-in mode / explicit combination mode

- **Specialized Tab host**: Segmented renders a real Tab and accepts compatible Tab Props at the root. There is no `parts.Tab`.
- Default built-in mode (recommended): `items` lets Tab generate Buttons; `parts.Button` configures those generated items.
- Explicit combination mode: explicitly write `<Button as="item">`, and directly configure Props item by item.

---

<a id="1-与-tab-的关系"></a>

<a id="与-tab-的关系"></a>

### Relationship with Tab

| Dimension | Tab | Segmented |
| --- | --- | --- |
| Meaning | Switch views or content panels | Choose one filter or parameter |
| ARIA role | `tablist` / child `tab` (hidden Button) | `radiogroup` / sub-item `radio` |
| Arrow keys | Move focus only (`selectionFollowsFocus=false`); Enter activates | Move focus and activate (`selectionFollowsFocus=true`) |
| Form integration | No | Yes (`name` attribute + internal hidden input) |
| Appearance (variant, size, tokens) | **Exactly the same** | **Exactly the same** |

Segmented specializes Tab: the real Tab owns the visible surface, interaction nodes, and root DOM. Segmented fixes `radiogroup` semantics, immediate arrow-key selection, and the hidden form input supplied by `name`.

Segmented inherits Tab’s composite hover rules. Items do not scale by default; they retain their color and indicator feedback. Enable scaling on a child Button or through `parts.Button.scaleOnHover=true`.

<a id="宿主-props-与所有权"></a>

### Host Props and ownership

- Type source: `ComponentProps<typeof Tab>`.
- Controlled fields: `value`, `children`, `role`, `itemRole`, `selectionFollowsFocus`, `class`, `parts`.
- Tab retains its variant, size, layout, indicator, keyboard behavior, Frame Props, and DOM.
- Segmented adds `radiogroup`/`radio` ARIA, immediate selection, a hidden input for `name`, and root-level class merging.
- Hidden input is the non-visual auxiliary node after the Tab root; it does not copy the Tab surface.

### 2.2 Child item contract

As in [Tab.md §2.2](../tab/reference.md), each child item must be `<Button as="item" value="...">`.

<a id="3-form-接入"></a>

<a id="form-接入"></a>

### Form access

```svelte
<Form onSubmit={data => console.log(data)}>
  <Segmented name="device" value="web">
    <Button as="item" value="web">Web</Button>
    <Button as="item" value="mobile">Mobile</Button>
  </Segmented>
</Form>

```

When `name` is set, Segmented appends `<input type="hidden" name={name} value={value}>` after the Tab root, exposing the current choice through native form submission.

<a id="6-键盘行为"></a>

<a id="键盘行为"></a>

### Keyboard behavior

- `←`/`→` in a row or `↑`/`↓` in a column: move focus and activate immediately (`selectionFollowsFocus=true`).
- `Home`/`End`: move to the first/last option and activate.
- The focus behavior is consistent with Tab (roving tabindex).

<a id="7-使用示例"></a>

<a id="使用示例"></a>

### Usage examples

```svelte
<script lang="ts">
  import { Button, Icon } from '@snowui-design-system/components';
  import { Segmented } from '@snowui-design-system/components';
  import { FourLeafClover, Star } from '@snowui-design-system/resource-svelte';
  let value = $state('web');
</script>

<Segmented bind:value variant="pill" size="md">
  <Button as="item" value="web"><Icon><FourLeafClover /></Icon>Web</Button>
  <Button as="item" value="mobile"><Icon><Star /></Icon>Mobile</Button>
</Segmented>


<Segmented fill style="width: calc(var(--size-20) * 4)" value="web">
  <Button as="item" value="web">Web</Button>
  <Button as="item" value="mobile">Mobile</Button>
</Segmented>


<Segmented variant="bare" value="all">
  <Button as="item" value="all">All</Button>
  <Button as="item" value="random" iconOnly aria-label="Favorite"><Icon><Star /></Icon></Button>
</Segmented>


<form>
  <Segmented name="device" value="web" variant="solid">
    <Button as="item" value="web">Web</Button>
    <Button as="item" value="mobile">Mobile</Button>
  </Segmented>
</form>
```
