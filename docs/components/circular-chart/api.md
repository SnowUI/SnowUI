# CircularChart API

These are named public Props; inherited capabilities belong to their own public API.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `data` | `CircularChartItem[]` | DEFAULT_DATA | Proportional items with required name and finite positive value, plus optional color and percentFormat. Invalid and nonpositive items are removed in input order before taking maxItems. Percentages divide by the visible item sum. Omitted data uses five demo items; an empty or wholly invalid array keeps final dimensions and renders an empty chart. |
| `size` | `number \| string` | 240 | Square chart size, preferably a positive number converted from design pixels to rem. String CSS lengths are passed through, but SVG geometry uses parseFloat without unit conversion; percentages, calc(), and CSS variables are unreliable for geometry. |
| `minWidth` | `number \| string` | `${SECTOR_CHART_MIN_WIDTH}px` | Minimum responsive display width. Numbers follow the same design-pixel-to-rem rule as size; strings are CSS lengths. Defaults to 40 CSS pixels. Set equal to size to prevent shrinking, or lower to permit it. Applies only with enableResponsive=true. |
| `ringThickness` | `number \| string` | 32 | Nonnegative design-pixel ring thickness. Inner radius is max(0, outer radius minus thickness); outer radius is size / 2 minus hoverThicknessGrowth minus 1. At the outer radius the ring becomes a solid pie. String values parse only their numeric part. |
| `cornerRadius` | `number \| string \| "auto"` | "auto" | Segment end radius in nonnegative design pixels at a 160×160 reference size, scaled by size / 160. auto uses 4. Final curvature is limited by ring thickness and available segment angle; 0 gives square ends. |
| `separatorWidth` | `number \| string \| "auto"` | "auto" | Transparent segment gap in nonnegative design pixels at a 160×160 reference size, scaled by size / 160. auto uses 2; 0 removes gaps. Path geometry leaves the actual background visible. |
| `colors` | `(CircularChartColor \| undefined)[]` | — | Override colors by visible filtered index. Entries accept semantic or CSS colors, variables, linear-gradient strings, or gradient objects with type, angle, and stops. Undefined positions fall back to colorMode; item color wins over the palette. Background utility class names are unsupported. |
| `colorMode` | `CircularChartColorMode` | "sequence" | sequence cycles Primary and nine Secondary colors. monochromeFade reduces one color evenly from 100% on the first item to 20% on the last (one item stays 100%). monochrome uses one color for all items. Item and palette overrides apply in every mode. |
| `color` | `CircularChartColor` | — | Override the fallback primary color for monochromeFade and monochrome ahead of monochromeColor or mutedMonochromeColor; sequence does not use it. Supports the same solid, semantic, and gradient formats as item color. |
| `monochromeColor` | `CircularChartColor` | "Primary" | Fallback primary color only for monochromeFade when color is absent. Supports solid colors and gradients. Opacity descends from 100% to 20%; item color and colors still win. |
| `mutedMonochromeColor` | `CircularChartColor` | "Black4" | Fallback only for monochrome when color is absent. The default Black4 is theme-adaptive and low contrast; segment fill opacity is not reduced further. Item color and colors still win. |
| `hoverThicknessGrowth` | `number \| string` | — | Nonnegative design pixels added outward on hover or focus. Inner radius and center stay fixed. If omitted, reads legacy hoverScaleSize, then 4. 0 disables geometry growth but retains data hints. String values parse only their numeric part. |
| `startDirection` | `StartDirection` | "top" | Start appearance from the segment crossed by the top, top-right, right, bottom-right, bottom, bottom-left, left, or top-left ray, then continue clockwise. It chooses the first animated segment without rotating data. Several rays may cross one large segment and give the same order. |
| `showBaseLayer` | `boolean` | false | Show a 4%-opacity layer in each segment’s final color and geometry. Off by default. It neither animates nor receives hits, and does not change actual segments or data. |
| `appearMotion` | `boolean` | true | Enable the appearance animation. false shows complete fill immediately and disables replay and reverseAppearance, while leaving hover thickness feedback active. |
| `appearOnView` | `boolean` | true | In uncontrolled mode, play once when the chosen anchor reaches a viewport line. Same-origin iframes use position in the outer same-origin page. false leaves playback to instance methods. appearanceProgress takes precedence; scrollAppearance uses a scroll timeline. |
| `appearanceProgress` | `number` | — | Controlled fill progress clamped to 0..1. Caller changes determine the view; automatic and instance playback cannot change it. appearMotion=false still shows full fill. External changes do not call onAppearanceProgressChange. |
| `defaultAppearanceProgress` | `number` | 0 | Initial uncontrolled progress clamped to 0..1 and read once. Later Prop changes do not reset motion; controlled appearanceProgress takes precedence. Default 0 is the unfilled outline state. |
| `appearanceDuration` | `number` | — | Total duration in milliseconds for instance and automatic playback, default 1000 regardless of segment count. Nonpositive values jump to the end on the next animation frame. Does not change scroll or controlled progress mapping. |
| `appearAnchorId` | `string` | — | ID of the page anchor for appearance. Defaults to the chart root when omitted; an ID that does not exist does not fall back. Affects automatic appearance and scroll timeline, not chart position. |
| `appearAnchorPoint` | `AnchorPoint` | "top" | Anchor top, center, or bottom compared with the viewport trigger line; does not change segment drawing direction. |
| `appearViewportPoint` | `number \| "top" \| "center" \| "bottom"` | 0.7 | Viewport trigger line from 0..1 or top=0, center=0.5, bottom=1. Default 0.7 means 70% of viewport height. Together with appearAnchorPoint it sets the trigger or scroll start. |
| `scrollAppearance` | `boolean \| { distance?: number \| string }` | false | Enable a window-scroll-driven uncontrolled timeline. Same-origin iframes also respond to outer-page scrolling. An object may override distance. Progress advances after the anchor passes the trigger line and reverses on upward scroll. Nested ScrollArea is not observed. appearanceProgress or appearMotion=false takes precedence. |
| `scrollAppearanceDistance` | `number \| string` | 320 | CSS-pixel distance for scroll progress from 0 to 1, as a number or numeric string, with minimum 1. scrollAppearance.distance takes precedence. Applies only with the scroll timeline; string units are not converted. |
| `onAppearanceProgressChange` | `(progress: number) => void` | — | Receives internal progress writes from 0..1, including direct completion during initialization, automatic playback, instance methods, and scrolling. Initial default value itself does not notify; external appearanceProgress changes are not observed. Return values cannot cancel updates. |
| `hoverScaleSize` | `number \| string` | — | Deprecated alias for hoverThicknessGrowth with the same units and behavior. Used only when hoverThicknessGrowth is omitted. It is not a scale ratio; new code should use hoverThicknessGrowth. |
| `maxItems` | `number` | 10 | Keep the first N valid items without sorting or merging Other. Integer-clamped to 1..10; 0 or NaN falls back to 10. Percentages use retained items only. Aggregate small categories before passing more than 10; wholly invalid data renders an empty chart. |
| `showCenterLabel` | `boolean` | true | Show the center content region. false hides dynamic default labels, segment-value and segment-name templates, and static center-label; it does not disable an explicitly enabled HoverPanel. |
| `hoverMode` | `ChartHoverMode` | "cell" | cell hits by angle across the ring, preserving the category through transparent gaps while excluding the center hole and outside. item only hits segment paths. Both modes retain keyboard focus hints. |
| `showHoverPanel` | `boolean` | true | Show a structured panel for the active hover or focus segment while retaining dynamic center labels. false disables it, except that a visible static center-label automatically enables a panel to carry segment information. |
| `hoverPanelVariant` | `ChartHoverPanelVariant` | "light" | Panel appearance: light glass by default, dark glass, or theme surface. It does not change data or hit behavior. |
| `hoverPanelPlacement` | `ChartHoverPanelPlacement` | "pointer" | pointer follows the pointer. anchor-top and anchor-side position relative to the current pointer point, or chart center for keyboard focus. pin-* fixes to the named chart edge or center, keeps an 8px edge gap, and participates in viewport collision handling. |
| `showHoverPanelLabel` | `boolean` | false | Show the active segment name above the panel data row. false shows only the row. Visible only with an active item and enabled panel. |
| `percentFormat` | `NumberFormatOptions` | — | Number format for center and panel percentages and segment aria-label. Supports fractionDigits, locale, and other NumberFormatOptions. Priority: item percentFormat, this Prop, NumberFormatContext, then the default one decimal. labelFormatter changes only center text. |
| `labelFormatter` | `(item: CircularChartItem, percent: number) => string` | — | On hover or focus, receives valid item and percent in 0..100 and returns center text. A newline splits at most two lines for value and name. Not called with static center-label or showCenterLabel=false; panel and segment aria-label percentages remain unchanged. |
| `loading` | `boolean` | — | Waiting-for-data state. Keeps final size and center content while holding segments at their appearance start and pausing interaction. When cleared, motion starts according to viewport conditions. Does not render Skeleton; also reads ancestor Frame loading context. Explicit data={[]} does not use demo data. |
| `children` | `Snippet` | — | Parameterless center Snippet when showCenterLabel=true. Direct Frame as="center-label" stays visible and enables the panel. Its direct Text as="segment-value" or as="segment-name" children can reuse default center layout with custom text. Direct Text roles outside it are dynamic templates filled by the component. The center is for display, not a toolbar. |
| `class` | `string` | "" | Additional class on the chart root Frame, empty when omitted. Styles the public root without penetrating internal SVG and label structure. |
| `style` | `string` | "" | Additional inline style on the root Frame after component variables. Use for external layout; prefer size and ringThickness for chart geometry. |
| `enableResponsive` | `boolean` | true | Shrink the chart proportionally when its container is short of width, including in side-by-side flex layouts. minWidth sets the minimum, 40px by default; matching width prevents shrinkage. HoverPanel does not scale. false keeps declared dimensions. Also passed to Frame. |
| `enableContext` | `boolean` | true | Forward the Frame context switch. Chart size, color, and appearance progress still use their own Props. |
| `enableScaleObserver` | `boolean` | false | Forward the legacy Frame size-observer compatibility switch, off by default. It is not percentage chart sizing and is not recommended for new examples. |
| `enableDefaultMotion` | `boolean` | true | Forward Frame outer default motion. It does not own the chart appearance timeline or segment hover thickening, which use appearMotion or appearanceProgress and hoverThicknessGrowth respectively. |
