# GradientMotion

Create a flowing gradient sweep for backgrounds, avatar placeholders, or clipped media areas.



Package: `@snowui-design-system/components`. Import: `import { GradientMotion } from '@snowui-design-system/components';`. Source fingerprint: `9f5529ac489aaf70ce9fa83040c2eb24c69d3921d338b8035e60cb2e9cd9423b`.

## Usage choices

Use GradientMotion as a decorative animated background. Prefer theme tokens for ordinary surfaces. Its art palette applies to this graphic only and is not a general UI color system.

- Choose the graphic with variant, pause it with paused, and adjust the effect with speed, intensity, and related props.
- Use a stable seed for a repeatable graphic identity. decorative is enabled by default. Animated colors do not replace theme colors.
