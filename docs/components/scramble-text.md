# ScrambleText

Reveal a target heading, short sentence, or status through a progressive character scramble.



Package: `@snowui-design-system/components`. Import: `import { ScrambleText } from '@snowui-design-system/components';`. Source fingerprint: `e1c0dd470387b42b2c3c8f32b838aea9be7128c0edb4afcc224fda743cfcd69f`.

## Usage choices

Use ScrambleText for a character-scramble effect when text changes. Use Text for static copy and FlowText for continuous text displacement. Keep content readable under reduced-motion preferences.

- text is the final text. mode, charset, and customSequence choose how characters change.
- Enable respectMotionPreference when the effect should honor system reduced-motion settings. Important information must always be expressible as final readable text.
