# SnowUILogo 更新日志归档

### v1.18.2 (2026-10-07)

- hover 目标启动间隔由 1200ms 缩短至 1000ms；保留完整过渡、稳定节点与不追赶补播规则。

### v1.18.1 (2026-10-06)

- 横版品牌字标与 hover 问候统一左对齐，图标继续同步切换 Emoji；纵版与纯字标保持居中。

### v1.18.0 (2026-10-06)

- 新增默认关闭的 idleMotion 开关，Site 仅在主页品牌 Logo 显式开启闲置旋转与飘浮；hover 行为保持不变。

### v1.17.1 (2026-10-06)

- 闲置动效由 CSS transform 改为 SVG 原生属性动画，保留周期、幅度与 hover 暂停，减少动画合成重采样导致的边缘发软。

### v1.17.0 (2026-10-06)

- 参考 Look Alive 的黄色图形与云朵，为闲置品牌 icon 增加整体慢转与上下飘浮；保留 hover 节点轮换，字标和命中范围不变。

### v1.16.1 (2026-10-06)

- hover 节点续播窗口由 5 秒延长至 10 秒；窗口内从最近完成节点的下一项继续。

### v1.16.0 (2026-10-06)

- hover 改为在稳定节点边界消费意图；图标、字母及品牌恢复均完整收尾，五秒内从上次完成节点的下一项续播。

### v1.15.3 (2026-10-06)

- 固定根节点悬停范围，避免动态溢出字形触发移入移出；递归计时不追赶繁忙帧，轮换加快至 1200ms。

### v1.15.2 (2026-10-06)

- Emoji 按实际可见边界匹配 icon 大小；图标和文字统一每 1800ms 同步轮换。

### v1.15.1 (2026-10-06)

- 修复纵向字标裁切和品牌字母恢复时横向移动；用实际字体 snowui 字形高度校准问候，随 Logo 等比缩放。

### v1.15.0 (2026-10-06)

- 图标与文字改为独立速度；图标缩放模糊交替，字标使用 Figma 分字矢量与独立逐字过渡，不依赖 NumericText。

### v1.14.0 (2026-10-06)

- 按用户要求改为表情与多语言问候循环，增加 vertical 的 compactProgress 连续收拢能力；保留四种组合及静态品牌几何。

### v1.13.0 (2026-10-05)

- 按 Workshop 更新彩色图标、双层旋转、主题底色叠加字标渐变和垂直组合比例；水平版与 icon/text 尺寸不变。

- 2026-09-21：统一使用文档、源码属性表与 Site / LLM 阅读入口；仅文档修订，不改变组件行为。

### v1.12.0 (2026-07-22)

#### 调整

- 品牌组件的源码、文档、Test 与注入入口统一采用 `SnowUILogo` 这一 PascalCase 文件及导出名。
- 明确导航链接由使用方组合，并新增原生 `<a>` 包裹 SnowUILogo 的返回主页 Test 示例；组件不新增 `href` Prop。

### v1.11.0 (2026-07-22)

#### 调整

- 固定品牌动效参数改为米字 `0.20x` 顺时针；蓝条 1/2 与蓝条 3/4 继续保持 `0.10x` 顺时针。

### v1.10.0 (2026-07-22)

#### 调整

- 固定品牌动效参数为米字 `0.30x` 逆时针、蓝条 1/2 与蓝条 3/4 均为 `0.10x` 顺时针。
- 移除公开 `speed`、`hoverMotion` 与 `loopMotion` 动效配置；Test 调节器保留为内部调试工具，不属于组件 API。

### v1.9.0 (2026-07-22)

#### 修复

- 修复持续 hover 时较快蓝条完成一圈后暂停、等待最慢米字结束的问题；五层现在按各自速度独立连续循环，直到退出 hover 后进入停靠阶段。

### v1.8.0 (2026-07-22)

#### 调整

- 默认速度改为米字 `0.15x`、蓝条 1/2 组 `0.30x`、蓝条 3/4 组 `0.60x`；同组蓝条同步旋转。
- 蓝条退出 hover 后就近停靠到 90° 整数倍，确保蓝条 1/2 中始终有一条位于 45° 斜角，蓝条 3/4 中始终有一条指向 12 点。
- Hover 动效调节器合并为米字、蓝条 1/2、蓝条 3/4 三组控制。

### v1.7.0 (2026-07-22)

#### 调整

- 退出 hover 后不再完成整圈，改为沿当前方向匀速停靠到最近的 `45°` 对齐点，使米字和蓝条各有一根轴线指向 12 点。
- 保留停靠角度，下一次 hover 从当前视觉角度连续开始，避免跳变。

### v1.6.0 (2026-07-22)

#### 调整

- 移除分段角度关键帧及速度变化，改为恒定角速度的线性整圈旋转。
- 米字与四条蓝条的默认旋转速度统一从 `0.25x` 调整为 `0.15x`。

### v1.5.0 (2026-07-22)

#### 调整

- 移除逐层等待与中途追赶汇合；米字默认顺时针旋转，四条蓝条同时同速逆时针旋转。
- 退出 hover 后五层沿当前方向完成整圈，全部回到初始角度后停止。

### v1.4.0 (2026-07-22)

#### 调整

- 将蓝条的独立 `animation-delay` 改为单一周期内的分层等待与追赶关键帧。
- 默认同速同方向时，五层在周期 50% 精确汇合于 215°，短暂恢复完整 SnowUI Logo 相对几何后同步完成后半程。
- 周期完成改为等待五个图层全部结束，独立调速时不会由最后一条蓝条提前截断其他图层。

### v1.3.0 (2026-07-22)

#### 调整

- 参考 loading.io Rosary / Microsoft loading 节奏，将逐层间隔从 10ms 扩大为 130ms。
- 旋转曲线改为前段快转、中段明显减速、后段再加速追完一周，让五层先后关系清晰可见。

### v1.2.0 (2026-07-22)

#### 调整

- `UI` 的两层浅色 Fill 改用主题 `white-100` Token，暗色模式自动切换为黑色叠加。
- 米字与四条蓝条的默认速度统一为 `0.25x`、默认方向统一为顺时针。
- hover 动效改为 10ms 逐层启动的完整单周期；中途移出时完成当前周期，仅阻止后续周期。

### v1.1.0 (2026-07-22)

#### 新增

- 新增 `hoverMotion`，可分别配置米字与四条蓝条的速度倍率和顺/逆时针方向。
- Test 新增 Hover 动效调节器，提供五层独立速度滑杆和方向切换。

#### 调整

- 登记旧版 `UI` 字样的三层 Fill 顺序；现行字标填充以本文“字标颜色”节为准。

### v1.0.0 (2026-07-22)

#### 新增

- 新增 SnowUILogo 组件，支持图标、字标、横向组合与纵向组合。
- 按设计稿登记四种形式的精确尺寸、图标/字标比例与组合间距。
- 新增 hover 分层旋转：白色米字顺时针，四条蓝色色条按从上到下的增速梯度逆时针，字标保持静态。
- 新增 `scale` 等比缩放、`speed` 速度倍率、循环时序覆盖与 reduced-motion 降级。
