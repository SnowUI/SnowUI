# ScrollArea 更新日志归档

### v1.2.0 (2026-07-22)

- 纵向 Thumb 保持常态 4px 视觉宽度，同时将常态 hover 命中宽度扩大到 hover 状态的 8px，降低指针命中难度。

### v1.1.0 (2026-06-21)

- 纵向滚动条默认隐藏，鼠标移入 ScrollArea 区域时使用 Frame 默认动效渐显、移出时渐隐；横向滚动条保持溢出时常显。

### v1.0.0 (2026-06-21)

#### 新功能

- 新增纵向、横向和双轴 SnowUI 自建滚动区域。
- 将页面/容器使用所需的 viewport、轨道、Thumb 和拖动逻辑封装为声明式组件。
