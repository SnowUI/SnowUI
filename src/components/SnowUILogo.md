# SnowUILogo（SnowUI 品牌标志）

> **版本**: v1.12.0
> **职责**: 按 Workshop 设计稿渲染 SnowUI 图标、字标，以及横向或纵向组合。
> **包归属**: OSS

SnowUILogo 是 SnowUI 的品牌视觉原子组件。图标与字标均使用设计稿原始矢量路径；组合形式、比例和间距会随 `scale` 一起等比缩放。

## 组件介绍

展示 SnowUI 图标、字标或组合标识，支持横向与纵向排列，适合品牌入口和页面署名。

## 布局模型

主布局模型：内禀原子布局。

- `icon`：设计基准为 `28 × 28`。
- `text`：设计基准为 `71 × 12`。
- `horizontal`：`28 × 28` 图标 + `6` 间距 + `71 × 12` 字标，整体 `105 × 28`。
- `vertical`：`64 × 64` 图标 + `8` 间距 + `71 × 12` 字标，整体 `71 × 84`。
- 内部图标与字标是固定品牌几何，不是公开 SnowUI 子组件，不接受 children，也不接入通用槽位。

## 关键字

| 关键字 | 类型 | 默认值 | 描述 |
| :--- | :--- | :--- | :--- |
| `variant` | `"icon" \| "text" \| "horizontal" \| "vertical"` | `"horizontal"` | 图标、字标或两种组合方向 |
| `scale` | `number` | `1` | 等比缩放图标、字标和组合间距；非有限值或非正数回退为 `1` |
| `decorative` | `boolean` | `false` | 设为 `true` 时从无障碍树隐藏 |

## 使用示例

```svelte
<SnowUILogo variant="icon" />
<SnowUILogo variant="text" />
<SnowUILogo variant="horizontal" />
<SnowUILogo variant="vertical" />
```

```svelte
<SnowUILogo variant="horizontal" scale={2} />
```

### 作为主页链接使用

SnowUILogo 只负责品牌视觉，不内置 `href`、路由或打开方式。需要点击 SnowUI Logo 返回主页时，由使用方使用原生 `<a>`、应用路由 Link 或其他导航宿主包裹：

```svelte
<a href="/" aria-label="返回 SnowUI 首页">
    <SnowUILogo variant="horizontal" />
</a>
```

这样可以由页面决定目标地址、客户端路由行为、`target` 与 `rel`，同时保持 SnowUILogo 的视觉职责稳定。

### 固定 Hover 参数

| 图层 | 速度 | 方向 |
| :--- | :--- | :--- |
| 白色米字 | `0.20x` | `clockwise` |
| 蓝条 1/2 组 | `0.10x` | `clockwise` |
| 蓝条 3/4 组 | `0.10x` | `clockwise` |

速度与方向属于 SnowUI 品牌动效的固定参数，不作为 SnowUILogo Props 或公开 CSS override。Test 中的 Hover 动效调节器仅用于内部调试和参数确认，不构成组件 API。

## Hover 动效

- 白色米字位于最上层，以恒定的 `0.20x` 速度顺时针旋转；蓝条 1/2 与蓝条 3/4 分别作为同步整体，均以 `0.10x` 顺时针旋转。
- 四条蓝色色条均以 Logo 1 (`#4C98FD`) 为底色；按设计图层从上到下叠加 `30% / 20% / 40% / 0%` 白色，最底层的 `0%` 保留统一绘制语义但不改变颜色。
- 旋转关键帧只定义 `0° → ±360°`，并使用 `linear` timing function；整个周期角速度恒定，不包含加速、减速或停顿。
- 指针仍停留时，各层以各自时长独立连续循环，不会等待其他图层完成当前圈。中途移出 hover 后不再完成整圈：米字与两组蓝条均沿顺时针匀速旋转，分别停靠至最近的 `45°` 与 `90°` 对齐点。
- 蓝条停在 90° 整数倍后，蓝条 1/2 中始终有一条位于 45° 斜角，蓝条 3/4 中始终有一条指向 12 点。
- 对齐后的实际角度会保留；再次进入 hover 时从该角度连续开始，不会瞬间跳回 `0°`。同组蓝条保持相同速度、方向和停靠位置。
- 组合形式只让图标部分旋转，字标目前没有 hover 效果。
- `prefers-reduced-motion: reduce` 下关闭内部旋转。

字标中的 `UI` 严格按 Figma Fill 顺序绘制：底层 Logo 2，上叠 `white-100/20%`，最上叠 `white-100/10%`；两层均消费主题 Token，因此在暗色模式中会切换为黑色叠加层。`Snow` 仍使用 Logo 2。

## 无障碍

默认输出 `role="img"` 与 `aria-label="SnowUI"`。纯装饰场景应传入 `decorative`；自定义可访问名称可传入 `aria-label`。

组件向 Frame 提供当前 variant 与 scale 对应的 `renderHints`；Skeleton 状态会保留同一外框尺寸。

## 开发者指南 (AI)

### 设计来源

- Workshop Figma 节点 `14012:38292`。
- 图标基准 viewBox 为 `32 × 32`，展示尺寸由 variant 与 scale 决定。

### 组合模式

SnowUILogo 是无 children、无公开内置子组件的品牌视觉原子组件，组合模式登记为“不适用”，不提供 `parts`。导航链接属于使用方组合，不改变组件模式。

### 私有动效值

SnowUILogo 的分层旋转只服务组件内部品牌图层，不与其他组件复用。组件消费 Frame `loopMotion` 的统一时序桥接；线性整圈旋转、各图层固定方向、蓝条 1/2 与 3/4 的分组速度，以及退出 hover 后米字停靠 45°、蓝条停靠 90° 对齐点的状态机是 SnowUILogo 私有视觉参数，不新增全局 Motion preset。
