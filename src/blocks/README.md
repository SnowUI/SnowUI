## 使用入口

- [Sidebar](./Sidebar.md)：应用导航外壳。
- [SidebarSection](./SidebarSection.md)：导航分组。
- [SidebarItem](./SidebarItem.md)：导航条目。

使用这些真实导出的组件组合导航；不要按分类示例推断不存在的导出。迁移前保持现有组件名、包名和公开 import，调用公开 Props / Snippets / events 与修改组件实现分别按 LICENSE 核对。
